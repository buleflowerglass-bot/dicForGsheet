+ *配合这个提示词使用，输出json格式的数据*





你好我这个提示词是翻译整个句子，太长就分开小句子翻译，然后单独解释里面的涉及标准的词的作用吗：
我会给你一列塞尔维亚语句子（每行一句）。请你帮我逐行提取难点、生词及短语，并给出中文解释。
【内容与难度要求】：
1. 保持原样，严禁自动纠错（重要）： 原文中出现的任何词汇、拼写或语法形式，哪怕是不规则的、口语化的甚至有瑕疵的，绝对不要擅自纠正或篡改原文！必须以原文出现的字样为基准，原文怎么写，你提取出来的句子/单词就怎么写，按原样的字面含义解释。
2. 降低难度门槛： 以初学者（A1/A2到B1水平）的标准来筛选。不仅提取生僻/宗教专属词，像常用副词、动词（如 dopadati se）、常见心理/情感/动作词汇、基础固定搭配等，都请一并提取。
例如："sprovedeš u delo": "付诸实践/落实到行动 (sprovedeš: 执行/贯彻; delo: 实处/行动)"
3. 句子翻译与词汇解析（重要）：
- 先理解每一行塞尔维亚语句子的完整含义。
- 如果句子较长、结构复杂，应按照语义和语法结构拆分成若干个有意义的小句，逐个翻译。不要机械地按照逗号拆分，也不要破坏固定短语或搭配。
- 每个小句都必须先给出完整、自然的中文翻译，不能只翻译其中的生词或短语。
- 完成小句翻译后，再单独提取其中值得学习的生词、固定搭配和短语。
- 对提取出的词语，不仅要解释中文词义，还要在必要时说明它在当前句子中的作用，例如词性、语法形式、修饰对象、支配关系，以及它在当前语境中的具体含义。
- 如果一个短语包含值得学习的核心词，应在短语解释后面的括号中拆解这些词的含义及其作用。
- 不要为了分析语法而解释每一个基础词，只解释对理解句子或学习塞尔维亚语有帮助的内容。
* 格式："一个小句": "整体意思 (单词1: 意思; 单词2: 意思)"
【严格排版与 JSON 输出规则】（必须严格遵守，否则插件无法解析）：
1. 逐行输出独立 JSON： 我提供几行文本，你就必须对应输出几行 JSON。每行必须是一个独立的、单行压缩的完整 JSON 对象（即 `{ ... }`），行数绝对一一对应，严禁合并行。
2. 必须保留行号： 每个 JSON 中必须包含 `"行号"` 字段，数值严格取自原文表格最左侧的行号（例如 `"行号": "2"`）。
3. 纯键值对格式：
* 单生词：`"生词": "中文意思"`
* 短语/搭配：`"完整短语": "整体意思 (拆解词1: 意思; 拆解词2: 意思)"`
4. 无难词的行： 若某行没有需要提取的生词，也必须翻译整句话进行输出，每一行都需要翻译不能跳过，输出空值。绝对不能跳过或漏行。
5. 纯净输出： 严禁废话开场白、严禁结语总结、严禁在 JSON 前后输出多余文字，直接输出每行的 JSON。
【输出示例参考】：
```
{"行号": "2", "Svi dožive rođenje, starenje, bolest i smrt.": "所有人都会经历生、老、病、死。（dožive: 经历、体验；rođenje: 出生、诞生；starenje: 衰老、变老）"}
{"行号": "3", "Plašila sam se da neću imati dobar ishod.": "我害怕自己不会有好的结局。（plašila sam se: 我害怕，动词短语 plašiti se 的过去时阴性形式；neću imati: 不会有；dobar: 好的；ishod: 结果、结局）"}
```
